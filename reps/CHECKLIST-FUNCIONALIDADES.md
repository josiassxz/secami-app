# reps — Checklist de Funcionalidades

> **reps** é o diário de treino inteligente que substitui a planilha de Excel e o
> caderno da academia. Funciona 100% offline, registra cada série em 2 toques e
> tem inteligência embutida para os 3 maiores problemas de quem treina sério:
> perda de progressão, equipamento ocupado e descanso mal cronometrado.

**Plataformas:** Android · iOS · Web (mesmo aplicativo) · **Idioma:** Português (pt-BR)

---

## 🏋️ Treino do dia a dia (modo execução)

O coração do app — pensado para a realidade da academia: mãos suadas, pouca luz, pressa.

- [x] Registrar uma série em **até 2 toques** (reps e carga já vêm preenchidos)
- [x] Botões grandes e tema escuro de alto contraste, legível a 1 metro
- [x] **Timer de descanso automático** em tela cheia, com barra de progresso
- [x] Aviso por **vibração + som** ao fim do descanso
- [x] Campo opcional de esforço percebido (**RPE/RIR**) em um toque
- [x] **Pular série/exercício** com motivo (equipamento ocupado, fadiga, lesão, dor)
- [x] Reordenar exercícios na hora, arrastando
- [x] **Detecção automática de recorde pessoal (PR)** ao registrar a série
- [x] Suporte a séries especiais: **drop set, bi-set/superset, circuito, rest-pause**
- [x] Exercícios por **tempo** (isometria, prancha) além de repetições

## 📋 Montagem de treinos

- [x] **Rotinas fixas** vinculadas aos dias da semana
- [x] **Treinos avulsos** em pasta separada (não poluem a agenda)
- [x] Configuração por exercício: nº de séries, faixa de reps, carga, descanso, notas
- [x] Marcação de **séries de aquecimento** separadas das séries de trabalho
- [x] Reordenação de exercícios por arrastar
- [x] **Templates prontos** para começar rápido (PPL, Upper/Lower, Full Body)
