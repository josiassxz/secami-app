## Findings considered and rejected

- **progression_providers null-bang fragility** (`progression_providers.dart:45`):
  code is currently correct; the `!` is guarded by control flow above it. Style
  smell, not a bug. Not worth a plan.
- **WorkoutController "race condition" on captured state snapshot**: Flutter runs
  the Dart event loop single-threaded; `Notifier` methods invoked from UI
  callbacks run to completion sequentially, so the captured-snapshot race isn't
  reachable. Rejected.
- **Sync per-row fallback lacks backoff** (`sync_engine.dart:286-295`): by design
  — per-row failures are typically server constraint violations that a delay
  won't resolve; the next sync cycle retries. Not a finding.
